### Build once. Explore everywhere.

Panori Studio is an authoring tool for creating rich 360° tours and spatial experiences. Connect scenes, place interactive hotspots, preview in VR and export a self-contained experience you can host anywhere.

### What you can create

- **360° virtual tours** with connected scenes and guided navigation
- **Interactive hotspots** for text, images, video, audio and 3D content
- **VR-ready experiences** for immersive viewing
- **Static exports** that remain under your control
- **Visual scene maps** for organizing complex projects

### Built for

🏡 **Real estate** · 🛍️ **Retail & showrooms** · 🎓 **Education & training** · 🏭 **Industry & manufacturing**
